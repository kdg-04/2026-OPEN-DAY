# 02. 시스템 설계

프로토타입 화면 4종에 담긴 설계를 정리한 문서다.
수치는 목업에 사용된 **표준 시나리오(30명 / 30분 / 7부스)** 기준이다.

---

## 1. 조 편성과 타임테이블 자동 산출

운영자는 세 가지 값만 입력한다.

| 입력값 | 예시 |
|---|---|
| 견학 인원 | 30명 |
| 체류 시간 | 30분 |
| 운영 부스 | 7개 |

여기서 배치표가 자동으로 도출된다.

```
조 수      = 부스 수 - 1                      → 6조   (1개는 항상 휴식 버퍼)
조당 인원  = 인원 ÷ 조 수                     → 5명
라운드 수  = 조 수                            → 6라운드 (전 부스 1회씩)
라운드 길이 = 체류시간 ÷ 라운드 수             → 4분
  ├ 미션 시간   3분 20초 (200초)
  └ 이동·세팅     40초
```

**부스 수보다 조 수를 하나 적게 잡는 것**이 이 설계의 핵심이다.
매 라운드 부스 1개가 비고, 그 부스가 라운드마다 순환하며 **지연 흡수 버퍼**로 작동한다.
어느 부스에서 시간이 밀려도 다음 라운드에 흡수되어 전체 타임테이블이 무너지지 않는다.

### 순환 라틴방격 배치

| | 1조 | 2조 | 3조 | 4조 | 5조 | 6조 | 휴식 |
|---|---|---|---|---|---|---|---|
| **R1** | **Vision Pro** | Ray-Ban | XREAL | R1/LOOI | Bedrock | AI 멜로디 | AI 인식 |
| **R2** | AI 인식 | **Vision Pro** | Ray-Ban | XREAL | R1/LOOI | Bedrock | AI 멜로디 |
| **R3** | AI 멜로디 | AI 인식 | **Vision Pro** | Ray-Ban | XREAL | R1/LOOI | Bedrock |
| **R4** | Bedrock | AI 멜로디 | AI 인식 | **Vision Pro** | Ray-Ban | XREAL | R1/LOOI |
| **R5** | R1/LOOI | Bedrock | AI 멜로디 | AI 인식 | **Vision Pro** | Ray-Ban | XREAL |
| **R6** | XREAL | R1/LOOI | Bedrock | AI 멜로디 | AI 인식 | **Vision Pro** | Ray-Ban |

- 같은 라운드에 두 조가 같은 부스에 있지 않다 → **대기열이 원천적으로 발생하지 않는다**
- 각 조는 각 부스를 정확히 1회 경험한다 → **체험 쏠림이 구조적으로 제거된다**
- 병목 부스(Apple Vision Pro)는 대각선에 놓여 **전 조 1회 배정이 보장**된다

## 2. 학생 앱 — 사용자 경험 3단계

개인 휴대폰으로 접속하며, **조당 1대만 있어도 작동**하도록 설계했다.

### STEP 1 · 브리핑

- 커너비 스토리 제시 — "커너비가 위험에 빠졌어. 구하려면 꿀이 필요해."
- 목표 꿀 제시 (예: 3,000)
- 배정된 조, 조 인원, 라운드 수 확인

### STEP 2 · 미션 (6라운드)

화면 구성:

- 현재 라운드와 조 (`R3 · 3조`), 남은 시간
- **당신의 역할** — 조작자 / 지시자
- 현재 부스와 미션명 (예: `Apple Vision Pro — 블랙박스 정비`)
- 미션 절차 (지시자에게만 표시)
- 조원별 상태 표시 (조작 완료 / 조작 중 / 지시)
- 라운드 잔여 타이머

### STEP 3 · 구출

- `MISSION CLEAR` — 커너비를 구했습니다
- 우리 반이 모은 꿀 총량
- 조별 랭킹 (우리 조 하이라이트)
- 참여 꿀 / 설문 꿀 분리 표시

## 3. 역할 분리 — 전원 참여를 만드는 규칙

이 프로젝트에서 가장 핵심적인 설계다.

기기가 1대뿐인 체험(예: Apple Vision Pro)에서 5명이 모두 참여하게 만들려면,
**한 사람이 혼자 완수할 수 없는 미션 구조**가 필요하다.

| 역할 | 가진 것 | 없는 것 |
|---|---|---|
| **조작자** | 기기, 실제 조작 권한 | 미션 절차를 모른다 |
| **지시자** | 미션 절차 (앱 화면) | 조작자의 시야를 볼 수 없다 |

### 예시 미션 — 블랙박스 정비 (Apple Vision Pro)

> 착용자에게는 **순서가 보이지 않습니다.** 말로만 지시해 엔진을 분해하세요.
>
> ① 카울링 분리 → ② 팬 블레이드 → ③ 연소실 → ④ 역순으로 조립

조작자는 무엇을 해야 할지 모르고, 지시자는 결과를 볼 수 없다.
미션을 완수하려면 **말로 협업할 수밖에 없다.**

### 조작자 교대

라운드마다 조작자가 순환한다.

```
6라운드 ÷ 5명 = 전원 최소 1회 직접 조작 (일부는 2회)
```

앱 하단에 조원별 조작 이력이 표시되어, 아직 조작하지 않은 사람이 누구인지 조원 모두가 안다.
**"소외되는 사람"이 시스템 화면에 드러나므로 자연스럽게 교대가 일어난다.**

## 4. 꿀(HONEY) 산정

| 구분 | 설명 |
|---|---|
| **참여 꿀** | 미션 수행에서 획득. 조작 참여 여부가 반영된다 |
| **설문 꿀** | 만족도 조사 응답 시 지급되는 보너스 (예: +150) |
| **조 점수** | 조원이 획득한 꿀의 합 → 조별 랭킹 |
| **반 점수** | 전 조의 합 → 메인 스테이지 게이지, 역대 기록 |

> **설계 원칙:** 설문은 **게이팅이 아니라 보너스**다.
> 응답하지 않아도 커너비는 구할 수 있지만, 응답하면 우리 반 기록이 올라간다.

> **참여도 차등 배분은 기획 단계에서 의도한 장치다.**
> 조 점수를 조원이 균등하게 나누면 구경만 해도 같은 꿀을 받게 되어,
> 역할 분리로 만든 참여 유인이 점수 단계에서 무너지기 때문이다.
> 직접 조작 횟수와 미션 기여가 개인 꿀에 반영되도록 방향을 잡았다.
>
> ⚠️ **[확인 필요]** 다만 **정확한 산식은 발표 당시 확정하지 못했다.**
> 실서비스 개발 시 별도 설계가 필요하다.

## 5. 메인 스테이지 — 꿀 게이지

센터 입구(1층~2층 사이) 대형 화면에 실시간으로 표시된다.

**구성**

- 반 전체 꿀 / 목표 꿀 (예: `2,238 / 3,000` — 74.6%)
- 대형 진행 게이지
- 6개 조 카드 (조별 꿀, 1위 조 왕관 표시)
- 하단 역대 반 기록 (1위 · 2위 · 지금 우리 반)
- 라운드 진행 인디케이터 및 잔여 시간

**설계 원칙 세 가지**

1. **경쟁 + 협력** — 조별 순위 위에 반 전체 목표를 얹는다. 다른 조가 잘해도 손해가 아니다
2. **실패 없음** — 게이지는 달성/미달이 아니라 **총량**을 표시한다. 커너비는 반드시 구해낸다
3. **다음 팀에게** — 모은 양이 반 기록으로 남아 다음 견학 팀의 도전 대상이 된다

## 6. 운영 인사이트 대시보드

게임 진행 중 쌓인 데이터가 그대로 센터 운영 데이터가 된다.

### 핵심 지표

| 지표 | 의미 |
|---|---|
| **직접 조작 참여율** | 실제로 기기를 조작한 학생 비율. 이 프로젝트의 핵심 KPI |
| **미션 완료율** | 배정된 미션 중 완료된 비율 |
| **평균 만족도** | 체험 후 1문항 응답 기준 |
| **평균 유휴 부스** | 설계값(버퍼 1개) 대비 실제 유휴 부스 수 |

### 분석 뷰

**① 부스별 평균 소요시간** — 배정 시간(200초) 대비 초과/여유를 막대로 표시
**② 병목 히트맵** — 부스 × 라운드 격자에 초과 발생 빈도를 색으로 표시
**③ 미션 만족도** — 미션별 별점 순위

### 자동 개선 제안

두 종류의 문제를 자동으로 식별한다.

| 패턴 | 진단 | 제안 |
|---|---|---|
| 소요시간 초과 + 만족도 높음 | 미션이 과하게 길다 | 미션 단계 축소 또는 라운드 길이 조정 |
| 소요시간 여유 + 만족도 낮음 | 미션이 얕거나 재미없다 | 미션 재설계 대상 |

> **선순환:** 체험 → 참여 데이터 → 콘텐츠 개선 → 다음 시즌 미션 반영

---

## 7. 수집 가능한 데이터

- 방문객 수 / 유형 / 조 구성
- 부스별 이용 횟수 · 평균 소요시간 · 초과 발생 라운드
- 개인별 직접 조작 횟수, 조별 진행률
- 미션별 만족도, 설문 회수율
- 시간대별 혼잡도, 전체 미션 클리어율
