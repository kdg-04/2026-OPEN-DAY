# 03. 실서비스 확장 로드맵

이 프로젝트는 아이디어톤 출품 단계에서 종료되었다.
실제 서비스로 개발할 경우를 가정한 단계별 계획이다.

---

## 원칙

처음부터 전체 플랫폼을 만들지 않는다.
**하루의 견학을 실제로 운영할 수 있는 최소 기능**을 먼저 완성한다.

```
QR 접속 → 조 배정 → 부스 미션 → 미션 완료 → 꿀 지급
        → 조 점수 집계 → 랭킹 표시 → MISSION CLEAR (커너비 구출)
```

이 한 줄이 끊김 없이 돌아가면 MVP다.
참여도 산정 · 만족도 연계 · 대시보드 · 데이터 분석은 그 다음이다.

---

## Phase 1 — 방문객 서비스 (MVP)

**목표:** 견학 1회를 실제로 운영해 본다.

- QR 접속 및 세션 참가
- 조 배정 확인
- 현재 라운드 / 부스 / 미션 표시
- 역할(조작자·지시자) 표시 및 라운드별 교대
- 미션 완료 처리 및 꿀 획득
- 조별 랭킹, 미션 클리어 화면
- 만족도 조사 1문항 + 설문 꿀

**검증 지표:** 직접 조작 참여율, 타임테이블 준수율

---

## Phase 2 — AI CREW 운영 도구

**목표:** 현장 요원이 앱만 보고 부스를 운영할 수 있게 한다.

- 담당 부스 및 방문 예정 조 확인
- 체험 완료 처리 / 참여 기록 입력
- 라운드 타이머 및 지연 알림
- 부스 대기·유휴 상태 보고

---

## Phase 3 — 운영자 콘솔 & 대시보드

**목표:** 운영 판단을 데이터로 한다.

- 인원/시간/부스 입력 → 조 편성 및 타임테이블 자동 생성
- 실시간 진행 현황 (완료 라운드, 참여 인증, 누적 꿀)
- 부스별 평균 소요시간, 병목 히트맵
- 미션별 만족도
- 메인 스테이지 화면 송출
- 견학 종료 후 리포트 자동 생성

---

## Phase 4 — 자동화 및 최적화

**목표:** 운영자의 판단을 시스템이 보조한다.

- 실측 소요시간 기반 라운드 길이 자동 보정
- 병목 부스 감지 시 배치 재조정 제안
- 미션 난이도 자동 튜닝 (소요시간 × 만족도)
- 방문객 유형별(중·고·대학·외국인) 미션 세트 추천
- 부스별 AI CREW 인력 배치 추천

---

## 확장 방향

```
                    AI DX CENTER
                          │
              ┌───────────┴───────────┐
        방문객 EXPERIENCE       운영 MANAGEMENT
              │                       │
        ┌─────┴─────┐           ┌─────┴─────┐
     Mission      Ranking    Dashboard   Analytics
        └───────────┴───────────┴───────────┘
                          │
                        DATA
                          │
                 운영 최적화 / 추천
```

단순한 "구출 미션 게임"이 아니라
**방문객 경험 관리 + 체험 운영 관리 + 데이터 분석**을 묶은 체험 운영 플랫폼으로 확장할 수 있다.

---

## 확장하더라도 유지해야 할 것

기능을 추가하더라도 아래 원칙은 바뀌지 않는다.

1. **모든 방문객이 다양한 체험에 실제로 참여한다** — 이것이 유일한 목표다
2. **커너비는 반드시 구해낸다** — 실패로 끝나는 견학을 만들지 않는다
3. **강제하지 않는다** — 만족도 조사는 게이팅이 아니라 보너스다
4. **구조로 해결한다** — 안내로 부탁하지 않고 배치와 규칙으로 문제를 없앤다

---

## 미확정 항목

실서비스 개발 시 별도 설계가 필요한 부분이다.

- **[확인 필요]** 개인 참여도 → 꿀 차등 배분의 정확한 산식
- **[확인 필요]** 부스별 꿀 보상 값의 산정 기준 (난이도 · 소요시간 반영 방식)
- **[확인 필요]** 조 편성 방식 — 완전 랜덤 / 사전 명단 기반 / 균형 배정 중 무엇을 기본값으로 할 것인가
- **[확인 필요]** 조당 기기 대수가 부족하거나 남는 경우의 역할 분리 변형
- **[확인 필요]** 외국인·교환학생 대상 다국어 미션 운영 방안
